The rule: list[start:stop:step]

start is included and stop is excluded, like Java’s substring(1, 3). So [1:3] gives index 1 and index 2 →
 [20, 30].
A slice always returns a list. Only a single index like nums[2] returns one value.
Negative index counts from the end: -1 is the last element, -2 the second-to-last.
step is how far to jump. ::2 takes every 2nd element from the start, so indices 0, 2, 4.
 ::-1 walks backwards, which reverses the list.
A blank start or stop means “from the beginning” or “to the end”.

index	    0	1	2	3	4
value	    10	20	30	40	50
negative	-5	-4	-3	-2	-1
